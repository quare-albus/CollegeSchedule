The parser first uses PDF text coordinates to establish the table columns. OCR is used as recognition evidence/fallback. Class type is taken from the Topic-column content; the remaining Topic-column content is kept as topic text, while Instructor is taken from the Instructor column. Wrapped lines inherit their visual column. No semantic guess is used to split a name from a topic.

Validation checks date, time ordering, term/session content, topic/venue recovery, and geometry confidence. Source page/line and raw evidence are retained. Nothing is stored in Supabase.

OCR backend: Supabase Edge Function ocrspace-proxy → OCR.space. The OCR.space API key remains server-side.
