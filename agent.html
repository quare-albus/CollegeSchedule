The OCR table is mapped by visual x-coordinate. In the source table, Topic is the class-type column and SLO contains the actual topic. Therefore this parser maps Topic → class type and SLO → topic. Instructor is taken only from the Instructor column. Wrapped OCR lines inherit their visual column. No semantic name/topic split is performed.

Nothing is stored in Supabase. Source page/line and raw OCR evidence are retained in the browser result.

OCR backend: Supabase Edge Function ocrspace-proxy → OCR.space. The OCR.space API key remains server-side.
